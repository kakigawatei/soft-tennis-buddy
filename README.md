# ふわとも ソフトテニスコーチ

ブラウザ上で動く、ソフトテニスのパートナーペットアプリです。スマホの中でキャラクターがふわふわ遊び、練習相談、結果メモ、ルール確認を手伝います。

## 起動

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## できること

- 相棒の名前を自由に変更
- キャラクター選択
  - ナンシキ村のこん
  - ナンシキ村のリー
  - 設定画面のプレビューカードから選択
- キャラクターごとの口調
  - こん: 落ち着いて寄り添うコーチ
  - リー: 明るく元気に背中を押すコーチ
- メインカラー変更
- スプライト画像の読み込み
  - 設定画面から元スプライト画像を読み込むと、左上の基本表情を自動で切り出して原画ピクセルのまま表示
  - 目の配置や線の太さを厳密に合わせたい場合は、この方式を使う
- 表情切り替え
  - スプライトシートから通常、笑顔、ウインク、びっくり、集中、ハート、しょんぼり、眠い表情を切り出し
  - 相談内容やタブ操作に合わせて表情が変化
- ボールのような動き
  - 画面内をゆっくり移動し、壁や床に当たると跳ね返る
  - キャラクターをタップまたはドラッグすると、ソフトテニスボールのように弾む
- ペットに話しかける相談チャット
- 試合スコアカウンター
  - 5/7/9ゲームマッチ対応、4ポイント先取＋デュース、ファイナルゲーム(7ポイント先取)
  - 1本戻す(取り消し)、リセット、相手名の記録
  - 試合終了後はワンタップで結果メモに保存
  - ゲームポイントやデュースで相棒が声をかける
- 成長グラフ（結果タブ）
  - 直近7日間の記録件数バーチャート
  - 記録テーマ(サーブ/レシーブ/前衛/後衛/ペア/メンタル)の分布
  - 相棒レベルとXPの進み具合
- ラリーミニゲーム
  - コート上の「ラリー」ボタンで開始、落ちる前にボールをタップして続ける
  - 続けるほどスピードアップ、ベスト記録を保存
  - 遊ぶと絆XPがたまる
- 目的と時間に合わせた練習メニュー生成
  - レベル、役割、今日の状態も反映
  - ねらい、本数、注意点つきのカード形式
- 今日の結果、できたこと、次の課題を保存
- ソフトテニスのルール事典
  - 試合、サービス、プレー中、審判、マナー、用具のカテゴリ切り替え
  - キーワード検索
  - 公式資料をもとにした初心者向けの要約カード
