# 集まれナンシキ村

ブラウザ上で動く、ソフトテニスのパートナーペットアプリです。スマホの中でキャラクターがふわふわ遊び、練習相談、結果メモ、ルール確認を手伝います。

## 起動

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## できること

- 相棒の名前を自由に変更
- キャラクター選択
  - ナンシキ村のコン
  - ナンシキ村のリー
  - 設定画面のプレビューカードから選択
- キャラクターごとの口調
  - コン: 落ち着いて寄り添うコーチ
  - リー: 明るく元気に背中を押すコーチ
- メインカラー変更
- スプライト画像の読み込み
  - 設定画面から元スプライト画像を読み込むと、左上の基本表情を自動で切り出して原画ピクセルのまま表示
  - 目の配置や線の太さを厳密に合わせたい場合は、この方式を使う
- 表情切り替え
  - スプライトシートから通常、笑顔、ウインク、びっくり、集中、ハート、しょんぼり、眠い表情を切り出し
  - 相談内容やタブ操作に合わせて表情が変化
- ボールのような動き
  - 画面内をゆっくり移動し、壁や床に当たると跳ね返る
  - キャラクターをタップまたはドラッグすると、ソフトテニスボールのように弾む
- ペットに話しかける相談チャット
- 試合スコアカウンター
  - 5/7/9ゲームマッチ対応、4ポイント先取＋デュース、ファイナルゲーム(7ポイント先取)
  - 1本戻す(取り消し)、リセット、相手名の記録
  - 試合終了後はワンタップで結果メモに保存
  - ゲームポイントやデュースで相棒が声をかける
- スコア分析モード（設定で切り替え）
  - サーブする選手（またはレシーブゲーム）を指定。サーバーは2ポイントごとに自動交代し、ゲームごとにサーブ権も交代
  - 自チームのサービスゲームは毎回選手1からサーブ開始（チップで手動変更も可能）
  - ファイナルゲームは2ポイントごとにサーブ権がチーム間で交互に移り、自チーム内でも順番に交代
  - フォルトボタン: 2回タップでダブルフォルト。サーブ側なら失点、レシーブ側なら得点
  - ダブルスの選手別に「誰が決めたか / 誰のミスか」をポイントごとに記録（選手名は変更可）
  - 相手チーム名・相手選手A/Bの名前も登録でき、採点票に転記される
  - 選手別の得点・ミス集計、ファーストサーブ確率、Wフォルト率（選手別）、ポイントの流れをドットで可視化
  - 記録ボタンはすべて1画面に収まり、スクロールなしで操作できる
  - 結果メモ保存時に選手別サマリーと次の課題を自動生成
- ジャッジペーパー出力（シンプル/分析どちらのモードでも）
  - 日本ソフトテニス連盟の「ダブルス・シングルス採点票」様式に準拠
  - スコアタブの「ジャッジペーパー」ボタンで印刷用シートを表示し、そのまま印刷・PDF保存
  - ゲーム①〜⑧+Ⓕの行に、取ったポイント=○・失ったポイント=✕を左右両チーム分自動転記
  - 各ゲームの得点（取った側を○囲み）、スコア欄のゲームカウント、S/Rの○囲み（分析モード）も自動
  - 種別・コート・回戦・正審・副審・線審・タイム・警告・勝者サイン等は空欄で手書き追記できる
- 成長グラフ（結果タブ）
  - 直近7日間の記録件数バーチャート
  - 記録テーマ(サーブ/レシーブ/前衛/後衛/ペア/メンタル)の分布
  - 相棒レベルとXPの進み具合
- 壁打ちミニゲーム
  - コート上の「壁打ち」ボタンで開始、指でラケットを自由に動かす
  - 縦持ちのラケットの面(ヘッド)でボールを捉えると打ち返す
  - ラケットを振った勢いで打球の強さが変わる(優しく当てると弱く、振り抜くと速い)
  - 打った球はノーバウンドで左の壁に当てる。手前でバウンドしたらミス
  - 壁から戻ってきた球はノーバウンドでも1バウンドでも打ててOK、2バウンドでミス
  - ヘッドの真ん中で打つと強い返球、続けるほど壁からの跳ね返りが速く低くなる
  - ベスト記録を保存、遊ぶと絆XPがたまる
- 目的と時間に合わせた練習メニュー生成
  - レベル、役割、今日の状態も反映
  - ねらい、本数、注意点つきのカード形式
- 今日の結果、できたこと、次の課題を保存
  - 結果タブは「練習の記録」と「試合の記録」に分かれる
  - 試合の記録をタップすると詳細分析を表示: 得点差の推移グラフ、ポイントの流れ、選手別の得点/失点バー、1stサーブ率・Wフォルト率
- ホーム画面に追加（PWA）
  - マニフェストとアプリアイコン（コン）つき。ホーム画面からアプリのように起動
  - iPhone: Safariの共有→「ホーム画面に追加」/ Android: メニュー→「アプリをインストール」（設定画面にも案内あり）
  - service workerでオフライン時も直近のキャッシュで動作（オンライン時は常に最新を取得）
- ソフトテニスのルール事典
  - 試合、サービス、プレー中、審判、マナー、用具のカテゴリ切り替え
  - キーワード検索
  - 公式資料をもとにした初心者向けの要約カード
